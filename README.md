# not-space-trash.github.io

Left Behind in Space – A Crayon Story of Falcon, Eagle, Dawn & Ginny.

## Development & Deployment

This repository is hosted via GitHub Pages from the root of `main`.

- `app.html` is the Vite HTML entry template used for development and builds.
- `index.html` at the repository root is the compiled single-file production bundle served by GitHub Pages.
- Run `npm run dev` to develop locally with Vite HMR.
- Run `npm run build` to rebuild `dist/index.html` and update the root `index.html` before committing changes.
